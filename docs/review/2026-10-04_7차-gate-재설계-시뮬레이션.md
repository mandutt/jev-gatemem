## 1. 문제 재확인

- **gate_only (원안)**: PLAUS 0건 주입 (완벽 차단) but **VALID 24건 과다거부** (LGO 19 + noans 5)
- 원인: gate NO는 사람 기준 VALID인 건도 80% 거부 — "직접 답 아님" 판정이 너무 보수적

## 2. 관찰 (사람 판정 × gate × score)

gate NO + 사람 VALID(오탐 19건)의 pointwise score:
```
0.9, 0.8, 0.74, 0.74, 0.74, 0.74, 0.72, 0.71, 0.65, 0.65,
0.6, 0.53, 0.52, 0.41, 0.31, 0.28, 0.24, 0.23
```
gate NO + 사람 PLAUS(정탐 5건)의 score: `0.72, 0.66, 0.65, 0.36, 0.28`

→ **gate NO인데 score가 높으면(=pointwise가 확신) 실제로 VALID일 가능성이 높음**.
   score가 낮은 gate NO만 abstain시키면 오탐 거부를 줄일 수 있음.

## 4. 채택 후보: **gateNO + score<0.7 → abstain** (R2)

```
gate=YES         → 주입 (100% VALID 실측)
gate=NO, score≥0.7 → 주입 (pointwise 확신 — 오탐 구제)
gate=NO, score<0.7 → abstain
```

**효과 (사람 판정 기준)**:
| 지표 | A 단독 | gate_only | **R2 (채택)** |
|---|---|---|---|
| LGO PLAUS 주입 | 5/90 (5.6%) | 0 | **1/90 (1.1%)** |
| LGO VALID 차단 | 0 | 19 | **10** |
| LGO VALID 주입 | 32 | 13 | **22** |
| noans PLAUS 주입 | 1 | 0 | **0** |
| noans VALID 차단 | 0 | 5 | **1** |

→ **gate_only 대비 VALID 차단 19+5 → 10+1 (절반 이상 감소), PLAUS 차단은 1건 누출만으로 유지**

## 5. 남은 과제: op hit@3에 미치는 영향 측정

- R2는 LGO/noans에서 검증됐지만 **op 90건에는 gate를 실행하지 않아** gate=UNKNOWN
- op 90건에 gate 1콜씩 (90콜 FREE) → R2 규칙 적용 시 hit@3 변화를 실측해야 함
- 핵심 의문: op에서도 gate NO + score<0.7인 VALID가 나와 hit@3를 깎는지

## 6. 결론 및 다음 단계

1. **R2 (gateNO+score<0.7)가 오프라인 최적** — 선택지 A(현행)보다 PLAUS 방어 5→1, gate_only보다 VALID 보존 2배
2. **op 90건 gate 적용 실험 (90콜 FREE)** 으로 hit@3 영향 확정 후 채택 여부 결정
