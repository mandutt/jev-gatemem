## 2. 실측 검증 — B의 지적 7건

### 2.1 noans n 비대칭 (A/B 15 vs C/D 50) — ✅ 확정
- 실측: A/B choice는 **15건**, C/D pointwise는 **50건** — 같은 집합 비교가 아님.
- **A도 1/15 = 6.7%로 5% 가드레일 초과** — "C는 위반, A는 통과"는 성립하지 않음. Wilson 95%: A [1.2%, 29.8%] vs C [4.3%, 21.4%] — 완전 중첩.
- → **가드레일을 "C의 FPR ≤ A 대비 +2pp" (baseline-relative)로 수정** + A/B도 같은 50건에 실행해 같은 분모로 비교 필요.

### 2.2 "운영 ≥90%" 조항 — ✅ 확정 (A 자신이 85.6%로 미달)
- 사전등록 채택 규칙 중 "운영 ≥90%"는 A(85.6%)조차 충족 못 함 → **90%는 과거 개발 gold의 reference 값이지 현행 baseline의 hard constraint가 아님**. "C가 A 대비 유의 개선 + 비열등" 기준으로 수정.
- 부수: A의 op hit@1이 이전 Run J 90.0% → 이번 82.2%로 하락한 이유 미서술 (B 지적) — **Run J는 라이브 데몬(+VEC_RANK_EXEMPT, pool 40) / 이번은 오프라인 스크립트 재현**으로 조건 차이 (추정). 보고서에 명시 필요.

### 2.3 D "86.2%, A와 동급" — ✅ 비짝 비교 (표현 완화 필요)
- D는 op 29개 부분표본 (25/29, Wilson [69%, 94%]), A 85.6%는 90개 전체 — **같은 쿼리 위 비교 아님**. new 포함 통합 59건에서는 D 42.4%.
- → "A와 동급"이 아니라 **"29개 부분표본에서 유망 신호"** 로 축소. A를 같은 29개에서 비교 필요.

### 2.4 B의 0% 원인 — ✅ 확정 (abstain 과발동 아님, 선택 판정 0건)
- 실측 (raw 전수): op_B 29건 중 **abstain 2건뿐** (upstream 404 / evidence 규칙). 나머지 27건도 **choice=None (선택 기록 없음)** — rank는 원래 pool 순위(8~1,285) 그대로.
- B의 "27건은 틀린 후보를 골랐다"는 세부는 틀렸으나, **"후보 절단/구현의 산물" 진단 방향은 정확**. criteria 64 한도에서 1,319행 choice는 토너먼트 경유인데 선택 판정이 사실상 0건 — **B 셀은 "choice full" 실험으로서 무효**.
- 3차 라운드에서 B 셀 정의 오류로 폐기 합의 → 4차에서 "A vs B 2차 대비"로 부활 (문서 이력 명시 필요 — b-ai 지적).

### 2.5 레인 전환 교란 — ✅ 확정 (raw에 레인 필드 없음)
- raw 레코드 필드: `src/qid/axis/cat/query/gold/cond/abstain/err/rank/top1/n_pool/max_score/choice/dataset` — **레인(무료/크레딧) 정보 없음**. 조건×레인 교차 구분 불가.
- `jev-latest`는 고정 버전이 아니므로 핀 문제 실재 — **레인별 레코드 수 표 + 동일 쿼리 20~30건 레인 교차 비교** 필요.

### 2.6 레코드 수 불일치 (238 vs 236, C 88) — ✅ 확정
- 실측: op 합계 = 90+88+29+29 = **236** (보고서 "238"은 오타). 총 874는 정확 (new 148 + syn 360 + noans 130 = 638, 236+638=874).
- **C 88건 = 90 - 2건**: 최초 err 2건이 재시도로 성공했는데도 레코드가 88뿐 — **동일 qid 덮어쓰기로 2건이 사라졌거나 실행 순서상 미포함**. 짝지은 분석(A 90 vs C 88 → 88쌍)에서 이 2건의 처리도 미명시. → raw 생성 스크립트 로그 대조 필요.
- 참고: 짝지은 n = op 88 + new 44 = **132** — B의 "n≈132" 정확.

### 2.7 "pointwise는 abstain 개념 없음" 부정확 — ✅ 확정
- C/D 오주입 정의가 이미 `max_score > τ` — **τ 자체가 abstain 메커니즘**. 문제는 개념 부재가 아니라 "τ와 점수 분포의 정합" (B) / "질문 문구가 relevance인지 answerability인지" (B 보충).

### 추가: C의 명칭 지적 — ✅ 확정
- A/C는 n=90/88+44+180+50, B/D는 29+30(합성 없음) → **균형 잡힌 2×2 factorial이 아님**. 문서 제목을 **"A/C primary ablation + B/D diagnostic full-scan"** 으로 수정 (수치를 약화시키지 않고 통계 신뢰성을 높임).

## 3. Q별 종합 판정

### Q1. A 유지 — **전원 (a). 확정.**
- 실측: op hit@3 A 85.6 > C 78.4 (+7.2pp), McNemar p=0.1796, 짝지은 차이 −4.5pp (10 vs 4), **CI 상한 < +5pp → "+5pp 개선 가설 기각"** (B). 통합 우위(C 72.1 vs 69.1)는 합성 16건 차이 (180/314 = 57% 가중)에서 나온 것.
- **기준 정리**: ①운영 지표 1차 ②가드레일은 baseline-relative ③통합은 층별(stratified) 보고로만 — "통합 대 운영" 대립은 지표 선택 문제가 아니라 보고 방식.
- 단 "pointwise가 전반적으로 열세"라고 말하지 말 것 — C는 연구 조건으로 유지 (전원 합의).

### Q2. pointwise 무답 10% — **(b) calibration 여지 우세 (B/C), A는 구조적.**
- 실측: noans max_score 45/50 ≤0.46, 오주입 5건(0.55~0.76) — **τ=0.65면 5→1(2%)**. τ sweep 여지 있음.
- 단 op hit@3 78.4%(C)가 τ 상향으로 더 떨어질 위험 (A 우려) — **API 호출 0회로 오프라인 ROC 가능** (raw에 max_score 저장됨, B 제안 채택).
- 가설 구분: noans 점수 분포가 "0.5~0.6 몰림"이 아니라 스파스 → (b) τ 문제보다 **질문 문구(relevance vs answerability)**  확인이 우선 (B 보충). C′ (answerability pointwise) 실험은 280요청.
- **가드레일은 "C ≤ A+2pp"로 수정** (2.1).

### Q3. new 44건 0% — **(c) gold 라벨/정합성 감사 우선 (B). A의 "코퍼스에 없음"은 반증.**
- 실측: ①D full 스캔에서 gold **30/30 발견** (rank 8~1,239) → "답이 코퍼스에 없다" ❌ ②C 기준 gold가 pool에 39/44 부재 → "pool 게이트 탈락" 부분 ✅ ③발견된 5건도 rank 9~17로 top-3 미달 → **관련성/라벨 문제 공존** ④A abstain 30/44는 "쓸 만한 증거 없음"의 정직한 선언에 일관.
- → "새 벤치 실패"가 아니라 **"gold provenance 미검증"** + **"신규 홀드아웃은 stress/validity strata로 분리"** (C). 검증: gold id 존재 확인 + (query,gold) 단독 채점 ~74요청 (B).

### Q4. 합성 역전 — **(c) 상호작용 효과 (B/C), 기각 자체는 (a) 타당.**
- "큐레이션 pool vs 노이즈 pool" 설명은 근거 부족 (B) — **주제 밀도 가설**: 운영 로그에는 동일 프로젝트 근접 문서가 많고 pointwise는 이웃 후보를 모두 높게 채점 → 점수 ≥τ 후보 수로 층별 검증. "운영 pool 정제 후 재실험"은 C에 유리하게 데이터를 바꾸는 방향이라 비추천 (B).
- 합성 벤치는 폐기하지 말고 **mechanism/stress test로 유지** (C) — "single-winner가 나쁘다"는 단순 결론을 실측으로 반박한 가치는 유지.

### Q5. B 0% / D 86.2% — **(a) full-scan production 기각 유지 + 표현 수정.**
- B: "full-scan+choice는 구조적으로 무효"가 아니라 **"1,319행을 63-candidate choice로 축약하는 구현은 무효"** (C) — 실행에서 선택 판정 0건 (2.4).
- D: "A와 동급" → **"29개 부분표본의 유망 신호"** (B/C). 기각 사유는 정확도가 아니라 ①비용 24~43배 ②무답 오주입 ③B 무효 — 유지.

### Q6. 다음 단계 — **(a) ⑤ 유지 + 저비용 진단 선행 (B) / (b) 진단 병행 (C) — 실질 합의: 진단 4종 후 ⑤.**
- B의 순서 (효율적): ①new gold id 존재 + 단독 채점 (~74요청) ②A를 noans 50 전체에 실행 (같은 분모) ③저장 점수로 τ ROC (0호출) ④(선택) C′ answerability 문구 (280요청) ⑤후회율 전향 감사.
- ⑥ cold tier는 우선순위 낮음 (전원) — 후회 0/103의 Wilson 상한 ~3.6%도 서두를 이유 없음. 단 그 표본(rejudge-SKIP 24 + (F,T) 79)은 write-gate SKIP과 분포가 다르다는 점 유의 (B).
