# §B. 작업 가설 — 반박 환영 (근거는 실측으로)

## B1. "pointwise 무답 오주입은 구조적 문제" (5차 Q2(a)) → 기각, τ 튜닝으로 해결됨

- choice는 **abstain 라벨 1개로 6.7%→2.0%** 방어 (프롬프트만으로, 튜닝 없음)
- pointwise는 **τ=0.65 하드코딩** 필요 — 운영 분포가 바뀌면 재보정 부담 존재

## 1. 문서 검토 질문 (Q1~Q6) — 각 질문에 선택지 + 근거 요구

### Q1. "C+τ=0.65 = 검증된 대안, A 유지" 판정의 타당성

C는 τ=0.65로 무답 가드레일을 통과했지만(0.0% vs A 2.0%), 운영 hit@3은 A보다 낮습니다(82.2% vs 85.6%).

- (a) **A 유지 타당** — op 지표가 1차 기준, C는 가드레일 통과 이상의 가치는 없음. A의 90% 미달(85.6%)은 C 도입이 아니라 별개 개선 과제
- (b) **A 개선 우선** — A(85.6%)가 목표 90% 미달인 이상, 대안 검증보다 A의 pool 커버리지 개선 실험이 우선
- (c) **C 도입 재검토** — noans 0.0%는 A보다 우수, 3.4pp 손실은 저신뢰 4건뿐 → 실제 사용 시나리오(무답 방어 우선)에서는 C가 나을 수 있음

**근거 형식**: (a)/(b)/(c) 택 1 + A(85.6%)와 C(82.2%)의 차이가 운영상 유의미한지(수치 인용).

### Q2. pointwise 오주입의 성격 — "구조적 문제" → "τ 튜닝으로 해결" 재판정

5차 Q2에서 (a) 구조적 문제로 판정됐으나, τ=0.65로 0.0% 달성으로 (b)가 실측 검증됐습니다.

- (a) **τ 튜닝으로 충분히 해결됨** — 구조적 문제 판정(5차 Q2(a))은 폐기, pointwise도 가드레일 준수 가능
- (b) **여전히 choice가 우월** — abstain은 프롬프트 1회로 방어(제로 튜닝) vs τ는 하드코딩 + 분포 변화 시 재보정. 운영 로버스트니스 기준 choice 우위 유지
- (c) **τ의 일반화 한계 실측 필요** — 6-3차는 1회성. noans 분포가 바뀌는 시나리오(예: 시간 경과)에서 τ=0.65의 로버스트니스를 검증하는 실험이 선행되어야 함

**근거 형식**: 택 1 + abstain(제로 튜닝)과 τ(튜닝 1회)의 운영 비용 비대칭 평가.

### Q3. new gold 44건 — 재큐레이션 가치

gold_score mean 0.328 (11%만 >0.5) — "gold가 코퍼스에 없어서 0%"가 아니라 "gold가 있지만 표면 일치가 낮아서"였습니다.

- (a) **재큐레이션 무의미** — 의역·신조어 쿼리에서 0%는 시스템의 실제 한계를 정직하게 보여준 것. 라벨을 원문에 가깝게 고치면 벤치가 낙관 편향
- (b) **재큐레이션 필요** — 44건은 "의역 내성"을 측정하는 벤치로 가치 있으나, 0.5 미만 gold 39건은 판정기 문구(모호함) 때문에 과소평가됐을 수 있음 → answerability 문구 개선 후 재측정
- (c) **answerability 판정기 문구 실험 우선** — C′ (5차 §7 선택 3) 280콜이 이제 무료 레인에서 2분이면 끝남. 판정기 문구가 gold 점수에 미치는 영향을 먼저 분리 측정

**근거 형식**: 택 1 + gold_score 0.328(의역 44건)이 문구 문제인지 실제 유사도 문제인지 추론.

### Q4. noans abstain 패턴 — choice 98% vs pointwise τ 0.0%

A/B(choice)는 98% abstain, C+τ=0.65(pointwise)는 50/50 전부 0.65 미만으로 **같은 50건을 다른 메커니즘으로 방어**했습니다.

- (a) **결과 동등 — 메커니즘만 상이** — 둘 다 무답을 0~2%로 방어, 실용 차이 없음. A 유지 결정에 영향 없음
- (b) **신호 차이 존재** — choice는 "abstain"으로 이진 판정, pointwise는 점수로 연속 판정. 후자는 τ 주변(0.54~0.65)에 실제 답안 4건이 존재해 **회색지대 정보가 더 풍부** → 디버깅·튜닝에 유리
- (c) **회색지대가 위험** — pointwise는 0.60 근처 noans가 존재(max 0.600), τ 한계 근처에서 오주입 위험. choice의 abstain은 그런 경계가 없음

**근거 형식**: 택 1 + max 0.600 noans와 op 0.54~0.60 손실 4건의 경계 중첩이 실용 리스크인지 평가.

5차 §7 선택 3(C′ answerability, 280콜)은 비용상 보류였으나, 무료 레인 실측으로 ~2분·0원이 됐습니다.

- (a) **재개** — 비용/시간 장벽 제거 확인. C′ 결과는 Q3(c)와 직결 (판정기 문구 vs 후보 점수의 분리 측정)
- (b) **보류 유지** — new gold 큐레이션(§B3) 결정이 먼저. C′은 gold 재라벨링 이후 의미 있음
- (c) **다른 실험이 우선** — A의 90% 미달(85.6%) 개선(예: pool 크기·RRF 가중치)이 C′보다 운영 가치 큼

**근거 형식**: 택 1 + 280콜(무료 2분)의 기회비용 대비 기대 정보량.
