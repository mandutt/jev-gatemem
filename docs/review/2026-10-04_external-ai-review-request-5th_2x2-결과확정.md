# §B. 작업 가설 — 반박 환영 (근거는 실측으로)

아래는 데이터가 "보여주는" 해석이지만 외부 검증으로 확정 대기 중입니다.

## B1. "A 유지" 판정 (Primary 해석)

- **C는 운영에서 개선 없음** (78.4% < 85.6%, p=0.1796) + 무답 오주입 10% > 기준 5% → 사전등록 채택 규칙상 **C 미채택, A 유지**.
- **쟁점**: 통합 지표(op+new+syn)에서는 C가 A를 앞섭니다 (hit@3 0.721 vs 0.691). 이는 합성 180건에서 C가 16건 더 맞힌(+8.9pp) 결과입니다. **"운영 우선 + 가드레일 우선" vs "전체 통합 지표 우선"** — 어느 쪽이 채택 기준으로 옳은가?

## B2. C/D 무답 오주입 10%의 원인 (미규명)

- 가설 (a): pointwise 프롬프트가 "1위를 뽑도록" 유도 → 무답도 1위로 lift
- 가설 (b): τ=0.5가 무답의 점수 분포와 정합하지 않음 (τ 재산정 여지)
- 가설 (c): pool 자체에 무관 후보가 섞여 pointwise가 점수화 (choice는 abstain으로 회피)
- **어느 가설이 맞는지 아직 실측으로 분리하지 못함** — 다음 라운드 실험 후보.

## B3. new 44건 hit@3 = 0%의 원인 (미규명)

- 44건 전부 gold가 pool 게이트(어휘·커버리지) 통과 실패로 추정 — pool에 gold가 없어 어떤 reranker도 못 맞춤.
- A abstain 30/44 (68%)는 choice가 "없다"고 정직하게 선언한 것일 수 있음 (오히려 정상 동작).
- **검증 필요**: 신규 쿼리가 실제로 "답이 없는" 쿼리인지, 아니면 벤치 설계(캐시·금칙) 문제인지. 4차 조건 ①이 요구한 "독립 홀드아웃"이 예상보다 가혹했을 가능성.

## B4. 합성 역전 (C 86.7 vs A 77.8)의 해석

- 합성 pool은 큐레이션된 후보라 pointwise의 독립 점수화가 유리 (노이즈 없음).
- 운영 pool은 실기억 노이즈(중복·부분 일치)가 많아 choice의 상대 비교가 유리.
- "합성에서 우위 = 도메인 이전 불가"로 기각 — **이 해석의 타당성 검토 요청**.

## 1. 문서 검토 질문 (Q1~Q6) — 각 질문에 선택지 + 근거 요구

### Q1. "A 유지" 최종 판정의 타당성

통합 지표에서 C가 A를 앞서지만(0.721 vs 0.691), 운영에서는 A가 앞서고(0.856 vs 0.784), C는 무답 오주입 가드레일을 위반합니다(10% > 5%).

- (a) **A 유지가 타당** — 운영 지표 + 가드레일이 1차 기준이고, 통합 우위는 합성 편향(큐레이션 pool)의 인공물
- (b) C 재평가 필요 — 통합 우위를 무시할 수 없음, C에 abstain을 추가하는 등 보완 실험 선행
- (c) 판정 보류 — 신규 44건의 hit@3=0%가 두 조건 모두 벤치로서 유효성에 의문 → 벤치 재설계 후 재실험

**근거 형식**: (a)/(b)/(c) 중 택 1 + 왜 통합 지표가/가 아닌 운영 지표가 채택 기준이어야 하는지 실측 인용.

### Q2. pointwise 조건의 무답 오주입 10% — 해결 가능한가, 구조적인가

choice(A/B)는 abstain 라벨로 6.7%까지 방어했지만 pointwise(C/D)는 τ=0.5로 10%입니다.

- (a) **구조적 문제** — pointwise는 abstain 개념이 없어 τ 튜닝으로도 한계. C/D는 원천적으로 가드레일 위반 → A 유지 근거 강화
- (b) **τ 재산정 여지** — 무답 전용 τ(예: 0.7)를 pointwise에 적용하면 방어 가능할 수 있음 → 재실험 가치 있음
- (c) **abstain 결합** — pointwise + abstain 라벨(무답용)을 criteria에 추가하는 하이브리드 제안

**근거 형식**: 택 1 + pointwise 무답이 1위를 lift하는 메커니즘에 대한 추론 (가설 B2 중 어느 것이 실측과 부합하는지).

### Q3. 신규 44건 hit@3=0% — 벤치 설계 문제인가, 시스템 한계인가

- (a) **시스템 한계의 실측 증거** — 신규 쿼리가 기존 코퍼스에 골드로 존재하지 않는 유형(완전 의역·새 도메인)이며, 이는 "커버리지 상한 ~90%"의 연장 → 벤치로서 정상, 시스템 개선 대상 아님
- (b) **벤치 설계 문제** — 신규 골드가 pool에 들어가도록 게이트 조건(어휘/커버리지)을 벤치가 무시해야 했음 (예: gold를 강제 주입한 조건부 측정) → 재설계 필요
- (c) **데이터 품질 문제** — 신규 44건 중 상당수가 실제로 답이 없거나 모호한 쿼리 → 큐레이션 재검토

**근거 형식**: 택 1 + 44건의 abstain 패턴(A 30건 abstain)이 어느 해석을 지지하는지.

### Q4. 합성 역전 — "도메인 이전 불가"로 기각하는 해석의 타당성

- (a) **기각 타당** — 합성 pool은 큐레이션(노이즈 없음), 운영 pool은 실기억 노이즈 — 두 pool의 통계적 성질이 다르므로 역전은 예상된 결과. 합성은 회귀 테스트로만 유지
- (b) **합성도 유효 신호** — C가 합성에서 일관되게 우위면, 운영 pool의 노이즈가 C의 잠재 우위를 가리고 있을 수 있음 → 운영 pool 정제(중복 제거) 후 재실험 가치
- (c) **둘 다 부분 타당** — 합성 우위는 pointwise의 "독립 점수화" 특성이며, 이는 운영에서도 (A가 우위인) 다른 요인(choice의 abstain 방어+상대 비교)과 공존 가능 — 조건별 상호보완이지 우열이 아님

**근거 형식**: 택 1 + 합성/운영 pool의 구성 차이가 역전을 설명하는지.

### Q5. B(choice full) 0% 붕괴 + D(pointwise full) 86.2% — full-scan judgment formulation의 해석

full-scan 조건에서 choice는 0%로 붕괴하고 pointwise는 A와 동급(86.2%)입니다.

- (a) **choice full-scan은 구조적으로 무효** — 후보 63개 제한 + abstain 과발동으로 1,319행 중 정답이 criteria에 포함될 확률 자체가 낮음. D의 결과는 "full-scan 자체는 정확도 문제가 아님"을 증명 (4차 보고서의 "열위" 표현 수정 확정)
- (b) **B의 0%는 abstain 과발동 때문** — (F,T)를 abstain으로 잘못 판정하는 choice 특성 → abstain을 제거한 full choice 재실험 가치
- (c) **full-scan 전반 기각 유지** — D가 86.2%여도 비용(24~43배) + 무답 10%로 도입 불가. 기각 사유는 정확도가 아니라 비용·가드레일

**근거 형식**: 택 1 + B 0%의 구체 메커니즘(후보 누락 vs abstain 과발동)에 대한 실측 추론.

### Q6. 다음 단계 우선순위

4차 §10의 잔여 작업: ⑤SKIP 후회율 전향 감사(shadow 누적 후) ⑥cold tier fallback(감사 후). 본실험 결과로 우선순위가 바뀌어야 하는가?

- (a) **⑤ 우선 유지** — 2×2는 "읽기 순위"만 측정, 쓰기 게이트 후회율은 별개 축. shadow가 쌓이는 대로 진행
- (b) **신규 실험 우선** — Q2(b)/(c)·Q3(b)의 미규명 지점(무답 오주입 원인 분리, 신규 벤치 재설계)이 먼저
- (c) **⑥ cold tier 우선** — B/D의 전체 스캔 결과(choice 붕괴·pointwise 동급)가 cold tier 설계(소형 vs 전체)에 직접 영향 → 설계 확정 전에 본실험 결과 반영 필요

**근거 형식**: 택 1 + 순서 변경 시 예상 비용/리스크.
