## 1. 조건 정의 (2×2)

| 조건 | 후보 공급 | Jev 판정 |
|---|---|---|
| **A** | lane pool + RRF (현행 운영) | choice 1콜 (abstain 포함) |
| **B** | full corpus (전체 행) | choice 1콜 |
| **C** | lane pool + RRF | pointwise relevance 배치 |
| **D** | full corpus | pointwise relevance 배치 |

- **Primary 비교**: **A vs C** = judgment formulation effect (choice vs pointwise) — pool 동일
- **2차**: A vs B = retrieval scope effect (pool vs full) — 판정 동일
- **탐색적**: D, A vs D 교차 — Holm 3쌍 이하 보정
- **EXPERLABS 게이트웨이 사용** (무료, 32질문/배치, 병렬 2 + 2초 대기)

## 2. 지표 (그대로 고정)

| 지표 | 정의 |
|---|---|
| **Hit@3** | 단일 gold: 상위 3위 내 gold 포함 비율 |
| **GoldRecall@3** | 다중 gold: gold 중 ≥1이 상위 3위 내 포함 (정답 2~5개 쿼리) |
| **MRR** | reciprocal rank 평균 |
| **Pool Recall** | gold-in-pool 비율 (커버리지, 조건 A/C 공통) |
| **무답 오주입률** | 무답 쿼리에서 Jev가 후보를 1위로 lift한 비율 (τ 보정 후) |
| **지연** | 쿼리당 총 지연 (Jev 호출 포함) |

- **공동 1차 지표**: Hit@3 + 무답 오주입률
- **2차 지표**: MRR, GoldRecall@3, 지연

| **무답 세트 (따로)** | ≥50 | 무답 쿼리 (운영 10 + 합성 무답 40+ 신규) — τ 보정용 |

- **dev/test 분리**: 운영 90(2축)은 dev, 합성 180 + 신규 ~30은 test (4차 보고서 §5.1 홀드아웃)
- **다중 gold 쿼리**: 합성에서 확보 (dataset_auto_v2는 gold_ids 2~5개 포함)

## 4. τ 보정 (무답 오주입률 판정용)

- **τ = max(0.5, 무답 질문 pointwise score의 90번째 백분위)** (사용자 선택)
- 무답 세트 ≥50개에서 산정 → 본실험 전 고정
- 무답 오주입 = τ 초과 후보를 1위로 lift한 쿼리 비율

## 5. 가드레일·판정 기준 (그대로 고정)

1. **점추정 차이 ≤2pp + 불일치 쌍 전수 수동 검토** (4차 §10-10, 비열등 CI 3pp 폐기)
2. **McNemar 짝지은 검정** (A vs C) — p<0.05 (Holm 3쌍 이하)
3. 효과 크기: Hit@3 +5pp 이상 (합성 Recall@3 포함 판정)
4. **"비결정적이면 A 유지"** — 채택은 explicit evidence 있을 때만
5. 운영 Hard Constraint: Acc@1 ≥90.0% 훼손 금지 (A/C 모두)
6. 무답 오주입률 ≤5% (τ 보정 후)

## 6. 실행 순서

1. ✅ 1~3단계 (skip_shadow, regret audit, probe) — 완료
2. **3.5단계**: 무답 dev/test 분리 + τ 보정 (무답 50+ 확보)
3. **4단계**: 2×2 본실험
   a. 실험 코드 작성 (32질문 배칭, 병렬 2+2s)
   b. 스모크 (각 조건 5쿼리) — 게이트: 전부 PASS
   c. 본실험 (n≈300) — A/C/B/D 순차
   d. 분석: Hit@3/GoldRecall@3/MRR/무답 오주입률/지연
   e. McNemar + Holm + 불일치 쌍 수동 검토
   f. 판정 보고서 + 실행 코드/raw 결과 커밋
4. **5단계**: SKIP 후회율 전향 감사 (shadow 누적 후)
