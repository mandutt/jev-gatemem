# 무료 레버 실측 보고 (R5 §4-4 후속) — 2026-10-01

> R5 합의 4번 "무료 레버 검토"의 두 후보를 라이브 데이터로 실측 판정.

## 레버 ①: 후보 텍스트 절단 (150~200자) — **기각 (이미 120자, 상향 시 비용 증가)**

현행 `_excerpt`는 이미 120자 절단 — R5가 상정한 "150~200자로 줄여 토큰 절감"은
현실과 반대(현행이 더 짧음). 상향은 절감이 아니라 비용 증가:

| excerpt 한도 | JEV state 문자수 (pool 40, 시뮬 200회) | vs 현행 120 |
|---|---|---|
| 120 (현행) | 3,948자 | 기준 |
| 200 | 5,906자 | +50% |
| 500 | 11,412자 | +190% |

그런데 절단 상향을 고려해야 할 이유도 발견: **gold 메모리 45건 중 40건(89%)이 120자를
초과** (median 371자). 즉 JEV가 보는 excerpt에 gold 정답 내용의 뒷부분이 잘려나가는
구조. 현재 Acc@1 83.3%로 충분히 높으나, 미래 정확도 개선 레버로는 "excerpt 상향 +
토큰 비용" 트레이드오프가 실존. 200자(+50% 문자) 시도는 소액이므로 다음 사이클 후보.

## 레버 ②: Score Calibration (S_jev + α·S_vec) — **기각 (기대 이득 +1.1%p 상한)**

Run J 실측 (n=90 gold, JEV 실호출):
- 순기여 lift (JEV가 정답을 1위로): **50건**
- 역기여 lift (JEV가 오답을 리프트해 정답 밀림): **6건** (그중 1위 빼앗김 1건)
- 무답 오주입: 0/10

혼합 스코어로 역기여 6건 전부 방지한다는 비현실적 가정에서도 Acc@1은 83.3→84.4%
(+1.1%p)가 상한. 실제로는 혼합 가중이 순기여 50건 중 일부를 깨뜨릴 수 있어 기대값
더 낮음. 리프트 구조 교체 대비 이득이 너무 작아 **현행 pure-lift 유지가 합리적**.

## 결론

| 레버 | 판정 | 근거 |
|---|---|---|
| ① excerpt 절단 | **기각** (이미 적용됨, 상향은 비용 증가) | 현행 120자 < 제안 150~200자 |
| ② Score Calibration | **기각** (상한 +1.1%p) | 역기여 6건 중 1위 빼앗김 1건뿐 |

**부수 발견**: gold 89%가 120자 초과 → excerpt 상향(200자)이 남은 16.7% 미스에
기여할 가능성. 다음 사이클에서 JEV 토큰 예산 여유가 있으면 Run K(200자) 실측 권장
(예상 비용: 90쿼리 × +50% 문자 ≈ 기존 Run J 토큰의 1.5배 수준).
