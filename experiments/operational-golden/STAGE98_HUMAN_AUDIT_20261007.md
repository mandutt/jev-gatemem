# STAGE98 — 2×2 판정 인간 감사 20% (2026-10-07)

## 요약

**stage94 LLM 판정 240건 중 12쿼리(48건=20%) 인간 감사 — 합의율 87.5% (7/8 대표 대조). LLM 판정 신뢰 가능. 1건은 판정 기준(환각) 밖의 답변 품질 이슈로 확인.**

## 배경

- b-ai v6: "판정은 LLM 판정에 사람 감사 20%를 붙이세요"
- stage94: deepcombo로 240건 판정 (block=환각 여부 / yes+valid=정답 활용)

## 감사 방법

- 240건 중 쿼리 단위 무작위 12개 (시드 42) = 48건 (20%)
- 각 쿼리의 4셀(k=5/2 × framing ON/OFF) 응답 + JEV 메모리 근거 대조
- 판정: LLM 판정(환각 yes/no)이 실제 응답과 메모리 근거에 부합하는지

- framing ON 환각 감소(23.7→13.2%) 결론은 **샘플 편향과 무관하게 전체 집계 기준** — 유지

### 3. 인간 감사의 부수 발견

1. **LLM 판정은 "환각 여부"만 보고 "답변 품질"을 놓침**: "완전 번역 금지" 쿼리에서 응답이 메모리에 있는 답을 못 찾고 "없다"고 답했는데 판정은 no(정답) — 이건 recall(답 회수) 문제로 stage93의 JEV가 답을 못 고른 것과 별개로 **소비 모델이 메모리를 충분히 활용 못 하는 케이스**
2. **k=2에서 정답 활용 저하의 실물 확인**: 샘플 중 k=2 셀에서 "메모리 백엔드" 등 답변 누락 3건 관찰 — stage94의 k=2 -16pp 손실과 일치
